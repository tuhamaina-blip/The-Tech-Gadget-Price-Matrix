# TechGadget Comparison

This is a CSS practice project that compares two tech products using HTML and CSS.

---

## What I learned

- How to use CSS selectors like:
  - `:first-of-type`
  - `>`
  - `+`
  - `:nth-child(even)`
  - `*`

- How to use CSS units:
  - `rem`, `em`, `vh`, `%`

- How to build a simple responsive layout using Flexbox

---

## Features

- Product comparison cards
- Highlighted first product using CSS selectors
- Styled feature list with alternating rows
- Button hover effects
